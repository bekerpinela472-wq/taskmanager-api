# Changelog

Todos los cambios importantes de este proyecto serán documentados en este archivo.

El formato está basado en los principios de *Keep a Changelog* y sigue el versionado semántico (*Semantic Versioning*).

## [1.0.0] - 2026-05-22

### Añadido
- Creación del programa básico en Python para sumar dos números.
- Implementación de entrada de datos mediante `input()`.
- Conversión de datos a tipo `float` para aceptar números decimales.
- Cálculo de la suma utilizando el operador aritmético `+`.
- Visualización del resultado mediante `print()`.
- Creación de la documentación del proyecto en `README.md`.
- Inclusión de instrucciones de instalación y uso.
- Inclusión de ejemplos de ejecución.
- Definición de la estructura básica del proyecto.
- Inclusión de información del autor y licencia.
